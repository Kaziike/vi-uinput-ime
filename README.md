# vi-uinput-ime

Bộ gõ tiếng Việt cấp hệ thống cho Linux sử dụng `uinput` + `evdev` + Custom XKB Keymap. Hoạt động độc lập, không phụ thuộc vào IBus hay Fcitx, tương thích với cả Wayland và X11.

## Cấu trúc dự án

- **[`vi-uinput-ime-telex/`](./vi-uinput-ime-telex)**: Bộ gõ tiếng Việt kiểu Telex.
- **[`vi-uinput-ime-vni/`](./vi-uinput-ime-vni)**: Bộ gõ tiếng Việt kiểu VNI.

Xem chi tiết hướng dẫn cài đặt, biên dịch và cấu hình tại `README.md` trong từng thư mục tương ứng.
